# libSceAgcDriver

## change [5_6_5 color targets]

- [5_6_5 color targets](../../../core/libs/prx/libSceAgcDriver/Graphics/src/State.cpp) (libSceAgcDriver) render into R5G6B5: X bits 0-4, Y 5-10, Z 11-15, per `ac_translate_colorswap` in [Mesa 26.2.2 ac_formats.c](https://gitlab.freedesktop.org/mesa/mesa/-/blob/mesa-26.2.2/src/amd/common/ac_formats.c). `SWAP_STD_REV` (2) puts red in 11-15 (exports unchanged); `SWAP_STD` (0) puts red in 0-4 (swaps X/Z, like 1_5_5_5); `SWAP_ALT`, `SWAP_ALT_REV`, and non-UNORM throw. Decoded format, mapping, mask, and host tests drawing 32_ABGR exports into tiled/linear targets in both orders pass; export direction, blend-constant routing, and dest alpha=1 (Vulkan rule) are unmeasured on PS5. Lacking DCC/MSAA clear-encoding entries, CB DCC decompress/eliminate with non-0000 codes and MSAA fast clears throw (like 1_5_5_5). PPSA27305 uses `SWAP_STD_REV` (discussion #6434).

## change [Layered color targets]

- [Layered color targets](../../../core/libs/prx/libSceAgcDriver/Graphics/src/State.cpp) (libSceAgcDriver): 3D targets with 64 KiB render-target or 4 KiB standard tiling render multiple slices, as does a `CB_COLOR_VIEW` slice range on a 2D array via its resident image or on a single-slice surface as `last_slice + 1` slices one slice pitch apart. Layered draws into an array without its resident image, with a depth target, or with mismatched slice counts throw. `PA_CL_VS_OUT_CNTL` USE_VTX_RENDER_TARGET_INDX reaches the shader only on layered draws; layers past the view's last slice are undefined in Vulkan (PS5 `SLICE_MAX` clamping unmodeled), while views past the surface clamp to its last slice. 3D DCC keys (1 key per 256 bytes across all slices) are interpreted only when uniform (all uncompressed or one fast-clear code), leaving mixed keys as-is; PS5 3D DCC key layout is unchecked (LEGO Horizon Adventures PPSA14632 uses DCC lighting volumes).

## change [Packed 16-bit textures]

- [Packed 16-bit textures](../../../core/libs/prx/libSceAgcDriver/Graphics/src/TextureFormat.cpp) (libSceAgcDriver): `5_6_5`, `1_5_5_5`, `4_4_4_4` use R5G6B5, A1R5G5B5, B4G4R4A4 (universal in Vulkan; R4G4B4A4 optional, absent in lavapipe), swizzled with X in low bits; `5_6_5` W reads X. Storage uses R16_UINT with [buffer UNORM store conversion](../../../core/shader/recompiler/SpirvBackend/src/SpirvImageEmitter.cpp) (nearest-even, NaN->0; ties/NaN unverified on PS5). `4_4` uses R4G4_UNORM_PACK8 (X low nibble). On RDNA2 (gfx1035), `image_load`/`image_sample_lz` return low/mid/high as X/Y/Z (+W, or X for `5_6_5` W). On RDNA2 (gfx1036, AMD Win 31.0.22044.1, wave32, 2D T#): `4_4` loads X/Y from low/high nibbles (256B); `image_store` to `5_6_5`/`1_5_5_5`/`4_4_4_4` maps NaN->0, clamps [0,1], rounds 0.5 up (1-bit `1_5_5_5` W->1); `4_4` store leaves 1,536B unchanged without fault. Wave64, other T#s, filtered sampling, PS5 unmeasured.

## change [Min/max S#]

- [Min/max S#](../../../core/libs/prx/libSceAgcDriver/Graphics/src/GuestSamplerResource.cpp) (libSceAgcDriver, recompiler) throws on linear mip filters, depth/color compare, or bilinear/anisotropic filtering of point-sampled images (sint, converted, depth-bits). With anisotropy, host reduces over its own footprint; [RADV](https://github.com/openbsd/xenocara/blob/1b39033df8d928ec247ca64448c4a63c72302db7/lib/mesa/src/amd/vulkan/radv_sampler.c#L185-L232) programs the same S#. On RDNA2 (gfx1030 [#5156](https://github.com/boykopovar/AnyPS5/pull/5156#issuecomment-6155265616), gfx1035 #5821), not PS5: `image_sample_lz` min/max with aniso bilinear/point gives bilinear/point min/max at ratio 0-4; `image_sample_d` (4:1 footprint) aniso bilinear at ratio 2/4 reduces across all aniso taps along the major axis. Non-AMD hosts use their own aniso footprint; Vulkan leaves nearest+aniso to the driver.

## change [VertexBufferReadSize]

- [VertexBufferReadSize](../../../core/libs/prx/libSceAgcDriver/Graphics/include/VertexInput.hpp) and [vertex staging copy](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Draw.cpp) (libSceAgcDriver): fetches >= `num_records` don't throw for `OOB_SELECT` 0/1; full copy zeros bytes from `num_records*stride`, yielding `(0,0,0,0)`. OOB fetches skip draw-snapshot cache; valid prefix flushes GPU writes.

## change [Image storage tables]

- [Image storage tables](../../../core/libs/prx/libSceAgcDriver/Graphics/src/ShaderResources.cpp) (libSceAgcDriver): every bound storage-table element is marked written and stored back per dispatch; overlapping elements write back in order (PPSA26344 compute 0x80001e5f00 binds stencil 0x505f350000 as R8_UINT and R8_UNORM in different tile modes). GPU per-element written bits and rejecting duplicate byte writers are unimplemented. Bindings declare full capacity (min of sampled capacity, 4096, `maxPerStageDescriptorStorageImages/4`), forcing dedicated pools without shrinking sampled capacity (risks layout validation failure). Elements whose set-wide index (incl. prior sampled elements) hits capacity are rejected and fault on lane select. Packed, BY2/BY4, dynamic-mip table stores fault. `PresyncSurfaces` walks sampled tables only. Mixed tables, RW T#s, non-uniform indexing, non-2D storage lack tests.

## change [User-data callees]

- [User-data callees](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Shaders/ShaderRegistry.cpp) (libSceAgcDriver): a compute shader's `s_swappc_b64` whose source pair is a user-data pair (or same-block `s_mov_b32`/`s_mov_b64` copy) reads the callee at dispatch up to its link-pair `s_setpc_b64`, appends a copy per call after the caller's last instruction, and rewrites the call to `s_call_b64`. Trailing words after the caller's last instruction are dropped from recompiled code; in seen shaders these are metadata/constants read PC-relatively from unchanged guest code, while jumping via a table among them (read from recompiled code by CFG analysis) throws. Because copies run at another PC, a callee that reads PC, makes calls, ends the program, jumps via another pair, returns before branch targets, exceeds 64 KiB, or is unreadable throws.

## change [Table callees]

- [Table callees](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Shaders/ShaderRegistry.cpp) (libSceAgcDriver): `s_swappc_b64` from `s_buffer_load_dword*` pair (or same-block `s_mov_b32/b64`, across forward branches) resolves if descriptor is `s_load_dwordx4` (or aligned `x8/x16`, no SOFFSET) via user-data or two `s_mov_b32`s and SOFFSET is `s_lshl_b32` 2-24. Backward CFG (fall-through, branch, resolved `s_setpc_b64`) allows unresolved `s_swappc_b64` (keeps descriptor; changes fault), forbids `s_call_b64`, fails at entry/`s_call_b64`/unreachable. Dispatch appends u64!=0 targets at `offset+k*stride`<size (`stride*num_records`, else `num_records`; PS5 unmeasured) per call via per-SCC chains (`s_cmp_lg_u32`/`s_cbranch_scc1`, `s_cmp_eq/lg_u32 0,0`, `s_call_b64`, fallback, `s_branch` relays). Throws if >64 targets (1024 [split](../../../core/shader/recompiler/ControlFlow/src/GraphBuilder.cpp)), >64 MiB, >0x7fff dwords from end.

## change [Host import windows and budget]

- [Host import windows and budget](../../../core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp) (libSceAgcDriver): >64 MiB ranges import per 64 MiB window (edge union); `AcquireRegistered` imports whole. Budget: `APS5_HOST_IMPORT_MIB`, else `max(6 GiB, RAM/2)`, <= `heap-clamp(heap/2,2..4 GiB)` (10466 MiB vs 8 GiB on 32/16 GiB; 2 GiB tight on 16 GiB). On `vkAllocateMemory` fail (within 1/8 or 3x row caps to live until device/config change), `VK_EXT_memory_budget` caps default <=1/s to `budget-other-1/8` in 64 MiB steps (logs `[gpu] host import budget: host heap ...`). Ignores `maxMemoryAllocationCount` (4096 NVIDIA vs 27,167 Village). Evicts LRU >2 frames (256 lookups pre-2 flips), else copies; refusals cache (step-down/join); mapped never evicts; address builds evict past `APS5_ADDRESS_COPY_MAX_MIB` (incl. write-watched mirrors). Logs `[gpu] host imports at shutdown`. Unmeasured: 64 MiB/2-frame/2 GiB/1/8/3-fail.

## change [Host import memory types]

- [Host import memory types](../../../core/libs/prx/libSceAgcDriver/Graphics/src/GuestBufferMemory.cpp): guest memory is CPU-read via the same pointer and Vulkan has no invalidation for imported memory (`vkInvalidateMappedMemoryRanges` requires `vkMapMemory`), so host-pointer imports require `HOST_VISIBLE | HOST_COHERENT` (preferring cached) and refuse candidates without it, copying and logging the step. Contexts with unknown memory properties (e.g. tests) keep the first candidate. Discrete-GPU driver types for host pointers are unmeasured: on RADV (Radeon 680M, Mesa 26.2.3) only coherent types appear, so refusal is tested by `agc_driver_graphics_tests` (`hostImportMemoryTypeTests`) rather than titles, and issue #6512's sentinel fill didn't reproduce there (700 runs of `agc_driver_multisample_fill_host_only`, 200 pinned to 2 CPUs, plus 200 on lavapipe). Dma-buf imports keep the first candidate.

## change [1D arrays past maxImageArrayLayers]

- [1D arrays past maxImageArrayLayers](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Texture.cpp) (libSceAgcDriver): 1D array views exceeding `maxImageArrayLayers` (at limit stays 1D array), sampled only via `image_sample_lz`/`image_sample_l` without depth compare or 128-bit T#, use a 2D image with two adjacent rows per slice; shaders enable this mode lazily. Layer selection rounds half-to-even and clamps to the view per [Vulkan's array layer selection](https://registry.khronos.org/vulkan/specs/latest/html/vkspec.html#textures-layer-selection). Measured on gfx1036 (driver 31.0.22044.1) via hardware oracle: absolute layers 0.5, 1.5, 2.5 select slices 0, 2, 2 of four; -1.0 and 5.0 clamp to first/last; NaN reads 0. Non-0 mip levels, block-compressed/RGBA8-expanded formats, native depth, other uses, >`maxImageDimension2D` rows, and `ShaderReplay` requests (no recorded limit) throw. PPSA08329 samples 5,120 slices.

## change [Reused address-based draw builds]

- [Reused address-based draw builds](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Draw.cpp) (libSceAgcDriver): measured only in PPSA01556's menu (~1 fps, local merge tree vs `main`, RTX 3070 Laptop GPU), matching via static-region pixel diff rather than frame hashes.
